# Viet Ride

Демо Telegram-приложения для аренды байков во Вьетнаме.

Два мира:
- **Чил** — лёгкие скутеры (Honda Vision, Honda Super Cub, Vespa) на улице у моря на закате.
- **Драйв** — мощные байки (эндуро, чоппер, стрит) в гараже.

Стартовый экран с анимированным фоном, каталог с видео-заездом каждого байка, бронирование с выбором дат, срока и опций.

Всё в одном файле `index.html`, видео и кадры лежат в папке `media/`. Цены и характеристики — демо-данные.
